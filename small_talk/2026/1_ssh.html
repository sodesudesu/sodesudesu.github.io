sshd の設定

Windows PowerShell （管理者）で 

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

してインストールだ！ 起動するには 

Start-Service sshd

をパソコン電源入れるたびに打ち込まないといけないと思っていたのだけど、なぜかそんなことない。 言われたらこれやればいいか。

あとは mac から優雅に

mac のターミナルから 

ssh username@IP

でとりあえず一旦 Windows に入室して 

wsl

で Ubuntu に潜入する。 直で Ubuntu に行くのは試したけどむずかった。

mac にあるファイルを編集したいので、 

sudo apt install sshfs
mkdir -p ~/mac_files
sshfs username@hostname:/Users/username ~/mac_files

する。 username は whoami コマンドで、 hostname は hostname コマンドで調べろバカ。
