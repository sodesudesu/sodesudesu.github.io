WSL2 でQualimap を動かす。

Qualimap と依存環境を準備

公式サイト の Download から qualimapv2.3.zip をダウンロードした。

QualiMap Online User Manual によると、Ubuntu にインストールするには

Qualimap requires:

JAVA runtime version 6 or above.

R enviroment version 3.1 or above.

らしいので、 

sudo apt install openjdk-17-jre 
sudo apt install r-base-core libxml2-dev libcurl4-openssl-dev

やった。

実行したいのに

起動スクリプトに Java 17 では使えないオプションが含まれていたので、 

sed -i 's/ -XX:MaxPermSize=1024m//' ~/qualimap_v2.3/qualimap

して消した。

実行権限を贈呈してやる： 

chmod +x ~/qualimap_v2.3/qualimap

これで起動できるようになった。 ふー。

BAM の QC やる

BAM の QC やるには 

~/qualimap_v2.3/qualimap bamqc -bam "hoge" -outdir "fuga"

を実行する。
